# CJ02-IMU 通信协议

## 概述

CJ02-IMU 通过 UART 输出二进制数据帧，默认配置 **460800 波特率, 8N1**。

**2026-09-06 量程更新：** 当前固件默认加速度量程为 ±16 g（2048 LSB/g）。
帧布局和 80 字节配置负载不变，帧内不携带量程标识。旧 ±2 g 固件使用
16384 LSB/g，必须配套对应版本的 SDK/Dashboard；混用会使加速度读数相差 8 倍。

输出数据流包含三种帧类型，输出率可配置为 1600/800/400/200 Hz：

| 帧类型 | 同步字节 | 长度 | 用途 |
|--------|---------|------|------|
| 原始数据帧 | `0xAA` | 16 字节 | 加速度计 + 陀螺仪原始值（按输出率分组平均） |
| 姿态帧 | `0xAB` | 20 字节 | ESKF 解算后的欧拉角 |
| 同步事件帧 | `0xAD` | 22 字节 | 外部触发事件（异步发送） |
| 配置命令帧 | `0xAC` | 变长 | 配置读写（双向） |

每个周期发送 **36 字节**（`0xAA` 16B + `0xAB` 20B）。1600 Hz 必须使用 2000000 baud；其余输出率支持 460800 或 2000000 baud。

常规 1600 Hz 模式需使用能稳定承载 2 Mbaud 连续流的 USB-UART。板载 WCH 调试器串口不适合该模式；`ENTER_VIBRATION` 的 1600 Hz 原始帧专用流可继续使用默认 460800 baud。

---

## 1. 原始数据帧（0xAA，16 字节）

包含加速度计和陀螺仪的原始 ADC 值。1600 Hz 直接输出；800/400/200 Hz 分别对连续 2/4/8 个 1600 Hz 样本分组平均，不跳点抽取。

```
字节   偏移   字段       类型         说明
─────────────────────────────────────────────────
 0     0      sync       uint8        0xAA 固定同步头
 1-2   1..2   acc_x      int16 LE     加速度 X（±16g，2048 LSB/g）
 3-4   3..4   acc_y      int16 LE     加速度 Y
 5-6   5..6   acc_z      int16 LE     加速度 Z
 7-8   7..8   gyr_x      int16 LE     角速度 X（±2000°/s，16.4 LSB/(°/s)）
 9-10  9..10  gyr_y      int16 LE     角速度 Y
 11-12 11..12 gyr_z      int16 LE     角速度 Z
 13-14 13..14 seq        uint16 LE    帧序号（每帧+1）
 15    15     checksum   uint8        字节 1..14 的异或校验
```

**单位换算：**

```
加速度 (mg) = raw_value × 1000 / 2048
角速度 (°/s) = raw_value / 16.4
```

## 2. 姿态帧（0xAB，20 字节）

包含 ESKF（误差状态卡尔曼滤波器）解算后的姿态角。

```
字节   偏移   字段       类型         说明
─────────────────────────────────────────────────
 0     0      sync       uint8        0xAB 固定同步头
 1-4   1..4   roll       float32 LE   横滚角（度，-180~180）
 5-8   5..8   pitch      float32 LE   俯仰角（度，-90~90）
 9-12  9..12  yaw        float32 LE   偏航角（度，-180~180）
 13-16 13..16 seq        uint32 LE    姿态帧序号
 17    17     mode       uint8        ESKF 模式（见下表）
 18    18     flags      uint8        状态标志（见下表）
 19    19     checksum   uint8        字节 1..18 的异或校验
```

**mode 字段：**

| 值 | 模式 | 含义 |
|----|------|------|
| 0  | INIT | 初始化中（倾斜初始化阶段） |
| 1  | RUN  | 正常运行 |
| 2  | NO_ACC | 无加速度计更新（自由落体/高动态） |
| 3  | REJECT | 观测被拒绝（NIS 检验未通过） |

**flags 字段（位掩码）：**

| 位 | 掩码 | 含义 |
|----|------|------|
| bit0 | 0x01 | 加速度计更新生效 |
| bit1 | 0x02 | ZARU（零角速度更新）生效 |
| bit2 | 0x04 | 检测到静止状态 |

---

## 3. 同步事件帧（0xAD，22 字节）

当外部传感器通过硬件触发引脚发送脉冲时，异步发送此帧（不占用 800 Hz 周期）。

```
字节   偏移   字段          类型         说明
─────────────────────────────────────────────────
 0     0      sync          uint8       0xAD 固定同步头
 1-4   1..4   trigger_seq   uint32 LE   触发时刻的内部采样计数器（1600 Hz）
 5-8   5..8   roll          float32 LE  触发时刻的横滚角（度）
 9-12  9..12  pitch         float32 LE  触发时刻的俯仰角（度）
 13-16 13..16 yaw           float32 LE  触发时刻的偏航角（度）
 17-20 17..20 att_seq       uint32 LE   当时的姿态帧序号
 21    21     checksum      uint8       字节 1..20 的异或校验
```

**用途：** `trigger_seq` 记录了触发脉冲到来时内部的 1600 Hz 采样计数器值。结合原始帧的 `seq` 字段，上位机可以精确对齐外部事件与 IMU 数据流（时间精度 1/1600 秒 = 0.625 ms）。

## 4. 配置命令帧（0xAC，变长）

用于上位机与传感器之间的配置读写。**双向使用同一格式**。

```
字节   偏移   字段       类型         说明
─────────────────────────────────────────────────
 0     0      sync       uint8        0xAC 固定同步头
 1     1      cmd        uint8        命令码（见下表）
 2     2      len        uint8        负载长度
 3..   3..    payload    uint8[len]   负载数据
 last  3+len checksum   uint8        字节 1..(len+2) 的异或校验
```

**命令码：**

| 值 | 命令 | 方向 | 负载 | 说明 |
|----|------|------|------|------|
| 0x01 | GET_CONFIG | 上位机→传感器 | 无 | 读取当前配置 |
| 0x02 | SET_CONFIG | 上位机→传感器 | 80 字节 | 写入新配置并保存到 Flash |
| 0x03 | RESET_CONFIG | 上位机→传感器 | 无 | 恢复默认配置并保存 |
| 0x04 | GET_FILTER_CONFIG | 上位机→传感器 | 无 | 读取滤波、输出率和波特率 |
| 0x05 | SET_FILTER_TEMP | 上位机→传感器 | 68 字节 | 临时应用到 RAM，不写 Flash |
| 0x06 | SAVE_FILTER | 上位机→传感器 | 无 | 保存当前滤波和传输参数 |
| 0x07 | RESET_FILTER | 上位机→传感器 | 无 | 关闭全部软件滤波，保留输出率和波特率 |
| 0x08 | ENTER_VIBRATION | 上位机→传感器 | 无 | 临时输出 1600 Hz 未平均原始帧，暂停姿态帧 |
| 0x09 | EXIT_VIBRATION | 上位机→传感器 | 无 | 恢复配置的常规数据流 |

**回复格式：** 传感器收到命令后回复，`cmd` 与请求相同，`payload[0]` 为状态（0x01=成功，0x00=失败）。

- GET_CONFIG 成功回复：`payload = [0x01] + 80字节配置数据`（len=81）
- SET_CONFIG 成功回复：`payload = [0x01]`（len=1）
- 失败回复：`payload = [0x00]`（len=1）

## 5. 配置参数（80 字节负载）

SET_CONFIG / GET_CONFIG 的负载包含以下 21 个参数，按顺序紧密排列：

| 偏移 | 类型 | 参数名 | 默认值 | 说明 |
|------|------|--------|--------|------|
| 0 | float32 | gyro_tilt_std_1s_deg | 0.3 | 陀螺倾角噪声 (°/s/√Hz) |
| 4 | float32 | sigma_gyro_bias | 3e-4 | 陀螺零偏漂移 (rad/s²) |
| 8 | float32 | gyro_scale_factor_error | 0.01 | 陀螺比例因子误差 |
| 12 | float32 | accel_variance_base | 0.05 | 加速度计基础方差 |
| 16 | float32 | accel_g_3sigma | 0.1 | 加速度 3σ (g) |
| 20 | float32 | accel_release_tau | 0.3 | 加速度释放 τ (s) |
| 24 | float32 | nis_reject | 50.0 | NIS 拒绝阈值 |
| 28 | float32 | nis_inflate_gamma | 6.0 | NIS 膨胀 γ |
| 32 | float32 | zaru_variance | 5e-4 | ZARU 方差 |
| 36 | float32 | static_gyro_threshold | 0.0524 | 静止陀螺阈值 (rad/s) |
| 40 | float32 | static_accel_rel_std_thresh | 0.026 | 静止加速度相对标准差阈值 |
| 44 | float32 | motion_gyro_full | 0.349 | 运动陀螺满量程 (rad/s) |
| 48 | float32 | motion_accel_full | 0.30 | 运动加速度满量程 (g) |
| 52 | float32 | initialization_tilt_seconds | 0.5 | 初始化倾斜时间 (s) |
| 56 | float32 | initial_attitude_variance | 0.00122 | 初始姿态方差 |
| 60 | float32 | initial_bias_variance | 2.5e-5 | 初始零偏方差 |
| 64 | float32 | maximum_delta_seconds | 0.05 | 最大 dt (s) |
| 68 | uint32 | zaru_static_frames | 300 | ZARU 静止帧数 |
| 72 | uint32 | motion_window_length | 200 | 运动检测窗口 |
| 76 | uint16 | trigger_divider | 0 | 触发输出分频（0=禁用，80=20Hz） |
| 78 | uint16 | trigger_duty | 20 | 触发输出占空比 (%) |

所有 float32 均为 IEEE 754 小端序。

### 滤波与传输配置（68 字节）

按小端序紧密排列：`flags(u32)`、`output_rate_hz(u32)`、`baud_rate(u32)`、
`accel_lpf_hz(f32)`、`gyro_lpf_hz(f32)`，随后依次为 3 个加速度陷波频率、
3 个加速度 Q、3 个陀螺仪陷波频率和 3 个陀螺仪 Q。

`flags` 位 0/1 分别启用加速度/陀螺仪低通，位 2..4 启用三组加速度陷波，
位 5..7 启用三组陀螺仪陷波。低通允许 5–600 Hz；陷波允许 10–700 Hz，
Q 允许 2–50。所有位默认关闭。滤波顺序为陷波后低通，仅作用于 ESKF 输入，
`0xAA` 原始帧不受影响。输出率只能为 1600/800/400/200；波特率只能为
460800/2000000，且 1600 Hz 要求 2000000。

## 6. 校验算法

所有帧的校验为**简单异或（XOR）**：将校验字节之前的所有数据字节逐个异或。

```python
def checksum(data: bytes) -> int:
    result = 0
    for b in data:
        result ^= b
    return result
```

---

## 7. 帧同步策略

数据流中可能出现帧错位（串口噪声、上位机中途连接等）。推荐同步策略：

1. 逐字节扫描，找到同步字节（0xAA / 0xAB / 0xAD / 0xAC）
2. 尝试解析完整帧并校验 XOR
3. **校验失败时，仅前进 1 字节**（不跳过整个帧长），继续搜索
4. 校验成功时，前进整个帧长，继续解析下一帧

这种策略能快速从错位中恢复，不会因数据字节碰巧等于同步字节而永久失步。
