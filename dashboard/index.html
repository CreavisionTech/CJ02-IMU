日志

Chrome / Edge 打开本页 → 连接串口 → 选 COM 口 → 波特率与固件一致（默认 460800）。固件经 USART1(PA2) 以 DMA 输出 0xAA 原始帧 + 0xAB 姿态帧，目标 800 Hz。点 ⚙ 配置 查看/修改 ESKF 参数与触发输出。

ESKF 参数配置

修改后点「保存到 Flash」下发固件并持久化（断电不丢）。触发输出在 PA0，分频=1600/频率（如 80→20Hz），占空比=高电平时间百分比。
